Work Experience Summary

Overview

My work spans embedded targets and cloud backends, with a focus on production-grade delivery under real-world constraints: deterministic timing, measurable latency/throughput, robustness, and maintainability. I build complete systems—from low-level interfacing and runtime integration through ML-enabled perception and optimization pipelines—primarily in C/C++ and Python, and I take responsibility for performance, reliability, and lifecycle considerations across development, validation, and deployment.

Embedded systems engineering

I develop and integrate embedded software stacks where hardware constraints, real-time behavior, and field reliability are central. My embedded experience includes both platform-level work and application-level pipelines, covering bring-up, integration, optimization, and validation in production contexts.

  • Real-time platforms and runtime integration (e.g., QNX), with attention to deterministic scheduling and system stability.
  • Low-level interfacing and synchronization for sensing/IO and timing-sensitive acquisition (e.g., I2C/SCI/STC/GPIO and related mechanisms).
  • Multithreaded pipeline design, synchronization primitives, and memory/buffer strategies for predictable performance.
  • Performance engineering across the stack: profiling, bottleneck isolation, vectorization, priority tuning, and latency control.
  • Hands-on debugging and validation using in-circuit and lab instrumentation (e.g., JTAG, logic analyzers, and related tools).

Embedded perception and real-time ML pipelines

  • Multi-modal camera pipeline integration with end-to-end timing control and robust runtime behavior.
  • 3D perception workloads for constrained targets, including object detection, pose estimation, and reconstruction.
  • Segmentation and related computer vision components integrated with embedded scheduling and memory constraints.
  • Compact model deployment using embedded runtimes (e.g., TFLite/TVM) and benchmarking with optimized math/acceleration libraries.

Machine learning, modelling, and optimization

I apply ML and mathematical modeling to capture physical-world behavior and improve decision-making in operational systems. The emphasis is on practical reliability: comparative evaluation, robustness to distribution shift, and integration with control and monitoring loops.

  • Anomaly detection and comparative evaluation across classical and deep approaches (e.g., Isolation Forest, Autoencoders, Deep SVDD, LoOP, and related methods).
  • Hybrid modelling approaches that combine first-principles dynamics with data-driven components.
  • Model predictive control (MPC) designs that improve prediction fidelity and control responsiveness in constrained settings.
  • Experiment design, metric definition, and rigorous validation (including accuracy/performance tradeoffs relevant to deployment).
